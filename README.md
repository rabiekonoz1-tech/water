# تطبيق معاينة المنشآت — شركة مياه الشرب والصرف الصحي بالمنوفية

مشروع متكامل (React Native / Expo + سيرفر محلي Node.js / SQLite) لإدارة المعاينات الشهرية للمنشآت الصناعية والمطاعم مع دعم كامل للعمل أوفلاين (Offline-First) ومزامنة تلقائية عند عودة الاتصال.

## المميزات الأساسية المنفذة
- **رفع خطط شهرية بصيغة Excel** بنفس تنسيق الشيت الحالي، مع استخراج المركز/المدينة تلقائياً من بادئة كود المنشأة (`SH`, `Q/QA`, `A`, `B`, `T`, `H`, `L`, `R`, `M`) أو العنوان، وحفظ جميع الشهور كأرشيف.
- **حجز مؤقت ("في الطريق") + قفل نهائي عند "تم"**: يمنع تكرار الزيارة، ولا يُفتح المكان المقفول إلا من الأدمن فقط.
- **موديول عينات ديناميكي للموظف**: يضيف الموظف أي عدد من العينات (اسم العينة، نوعها، العدد) + ملاحظات + GPS + توقيع (بدون رفع صور).
- **تعاون الفريق (زي جروب واتساب)**: شاشة نشاط الفريق تعرض تحركات ومعاينات كل الزملاء وتفاصيلها.
- **دخول بالكود فقط**: الأدمن ينشئ أكواد العمال ويديرها.
- **أوفلاين بالكامل (SQLite + Sync Queue)**: الحجز والمعاينات تتحفظ محلياً وتُزامن تلقائياً عند عودة الشبكة.

## ما الجديد في هذا الإصدار (تطوير المضمون)

### نموذج المعاينة (الحقل والميدان)
- **نتيجة الزيارة**: تمت المعاينة / المنشأة مغلقة / رفض المعاينة / غير موجودة بالعنوان / أخرى. غير المكتملة تتطلب سبباً وتُقفل كزيارة غير مكتملة (والأدمن يعيد فتحها).
- **العينات**: كود عينة تلقائي (`SH2-S1`)، اختيار سريع لنوع العينة، وقياسات ميدانية لكل عينة (**pH** من 0 إلى 14 و**درجة الحرارة**).
- **قائمة الاشتراطات**: ترخيص الصرف، وحدة المعالجة المبدئية (وجودها وعملها)، مصيدة الشحوم (وجودها ونظافتها)، إتاحة نقطة سحب العينة، وجود توصيلة مخالفة — مع **اقتراح تلقائي لمستوى المخالفة** (لا توجد / بسيطة / جسيمة / خطيرة) قابل للتعديل.
- **ممثل المنشأة** (الاسم والهاتف) و**طلب متابعة** بتاريخ اختياري.
- **حفظ مسودة تلقائي**: لو اتقفل التطبيق أثناء المعاينة، البيانات ترجع كما هي.
- GPS يُلتقط تلقائياً عند فتح النموذج.

### الحجز والمزامنة (إصلاح فقد البيانات)
- **انتهاء الحجز المؤقت تلقائياً** بعد 6 ساعات (قابل للتعديل بمتغير `RESERVATION_TTL_HOURS`) حتى لا يبقى مكان محجوزاً للأبد.
- **إلغاء الحجز** من صاحبه أو الأدمن (زر "إلغاء الحجز").
- **لا تضيع أي معاينة**: لو اتنين عاينوا نفس المكان أوفلاين، المعاينة الثانية تُحفظ كـ"مكررة" وتظهر للأدمن لمراجعتها (تجاهل أو اعتماد بدل الأولى) بدل ما تتمسح بصمت.
- **منع التكرار**: كل معاينة لها `client_id` فلو الطلب وصل والرد ضاع لا تتسجل مرتين.
- التطبيق الآن يفرّق بين "السيرفر رفض" (يظهر السبب وتبقى بيانات النموذج) و"مفيش نت" (تُحفظ في الطابور). ونتيجة المزامنة تظهر للمستخدم بالتفصيل.
- إعادة فتح مكان مقفول تؤرشف المعاينة القديمة بدل حذفها.

### للإدارة
- **لوحة متابعة**: نسبة الإنجاز، الإنجاز لكل مركز، المخالفات حسب المستوى، الزيارات غير المكتملة، أكثر الاشتراطات مخالفةً، أداء كل معاين، إجمالي العينات.
- **تصدير تقرير Excel** للشهر (أوراق: المعاينات، العينات، ملخص المراكز) باتجاه RTL.
- **شاشة المتابعات**: كل المنشآت التي تحتاج زيارة لاحقة عبر الشهور، المتأخرة بالأحمر، مع فتح الاتجاهات.
- **سجل المنشأة**: يظهر في الخطة تنبيه للمنشآت التي لها مخالفة جسيمة/خطيرة في شهور سابقة (يتم احتسابه بكود المنشأة)، وعند رفع الخطة يظهر عددها.
- منع رفع خطتين بنفس اسم الشهر، وتصنيف نوع النشاط تلقائياً (مطعم/مغسلة/مصنع/محطة/مزرعة) وملخص بالمراكز عند الرفع.
- إيقاف/تفعيل أكواد الموظفين، وتصفية الخطة بالحالة (متاح / في الطريق / تم / خاصتي).
- إصلاح: مطابقة عناوين أعمدة Excel القصيرة (مثل `م`) كانت تطابق أي عمود.

### ترقية قاعدة بيانات قديمة
لا حاجة لأي خطوة يدوية: السيرفر يضيف الأعمدة الجديدة تلقائياً لقاعدة `inspections.sqlite` الحالية عند أول تشغيل.

### واجهات API الجديدة
`GET /api/meta` • `POST /api/facilities/:id/release` • `GET /api/plans/:id/stats` • `GET /api/plans/:id/export.xlsx` • `GET /api/followups` • `POST /api/inspections/:id/followup-done` • `GET /api/conflicts` • `POST /api/conflicts/:id/resolve`

## التشغيل المحلي السريع

### 1) تشغيل السيرفر المحلي (Backend)
```bash
cd backend
npm install
npm start
```
يعمل السيرفر على المنفذ `4000` ويحفظ قاعدة البيانات تلقائياً في `backend/data/inspections.sqlite`.

### 2) تشغيل تطبيق الموبايل (React Native / Expo)
```bash
cd mobile
npm install
npx expo start
```
امسح الـ QR Code بتطبيق **Expo Go** على موبايلك، واضبط عنوان السيرفر المحلي (IP جهاز الكمبيوتر مثل `http://192.168.1.10:4000`) من شاشة الدخول.
